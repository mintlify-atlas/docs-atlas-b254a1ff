## Overview

The `torch.cuda` package adds support for CUDA tensor types that utilize GPUs for computation. It implements the same functions as CPU tensors but leverages GPU acceleration.

It is lazily initialized, so you can always import it and use `is_available()` to determine if your system supports CUDA.

## Device Management

<AccordionGroup>
  <Accordion title="torch.cuda.is_available()">
    Returns a bool indicating if CUDA is currently available.
    
    <ResponseField name="available" type="bool">
      True if CUDA is available on the system.
    </ResponseField>
    
    ```python
    import torch
    
    if torch.cuda.is_available():
        print("CUDA is available!")
        device = torch.device('cuda')
    else:
        device = torch.device('cpu')
    ```
  </Accordion>

  <Accordion title="torch.cuda.device_count()">
    Returns the number of GPUs available.
    
    <ResponseField name="count" type="int">
      Number of CUDA devices.
    </ResponseField>
    
    ```python
    >>> torch.cuda.device_count()
    4  # 4 GPUs available
    ```
  </Accordion>

  <Accordion title="torch.cuda.current_device()">
    Returns the index of the currently selected device.
    
    <ResponseField name="index" type="int">
      Index of current CUDA device.
    </ResponseField>
    
    ```python
    >>> torch.cuda.current_device()
    0
    ```
  </Accordion>

  <Accordion title="torch.cuda.set_device()">
    Sets the current device.
    
    <ParamField path="device" type="int or torch.device" required>
      Selected device index.
    </ParamField>
    
    ```python
    torch.cuda.set_device(0)  # Use GPU 0
    x = torch.randn(100, 100).cuda()  # Goes to GPU 0
    ```
  </Accordion>

  <Accordion title="torch.cuda.device()">
    Context manager that changes the selected device.
    
    <ParamField path="device" type="int or torch.device" required>
      Device index to select.
    </ParamField>
    
    ```python
    # Default device is 0
    x = torch.randn(100, 100).cuda()
    
    # Temporarily use GPU 1
    with torch.cuda.device(1):
        y = torch.randn(100, 100).cuda()  # On GPU 1
    
    # Back to GPU 0
    z = torch.randn(100, 100).cuda()  # On GPU 0
    ```
  </Accordion>

  <Accordion title="torch.cuda.get_device_name()">
    Gets the name of a device.
    
    <ParamField path="device" type="int or torch.device">
      Device index. If None, uses current device.
    </ParamField>
    
    <ResponseField name="name" type="str">
      Name of the CUDA device.
    </ResponseField>
    
    ```python
    >>> torch.cuda.get_device_name(0)
    'NVIDIA GeForce RTX 4090'
    ```
  </Accordion>

  <Accordion title="torch.cuda.get_device_capability()">
    Gets the compute capability of a device.
    
    <ParamField path="device" type="int or torch.device">
      Device index. If None, uses current device.
    </ParamField>
    
    <ResponseField name="capability" type="tuple[int, int]">
      (major, minor) compute capability version.
    </ResponseField>
    
    ```python
    >>> torch.cuda.get_device_capability(0)
    (8, 9)  # Compute capability 8.9
    ```
  </Accordion>

  <Accordion title="torch.cuda.get_device_properties()">
    Gets the properties of a device.
    
    <ParamField path="device" type="int or torch.device" required>
      Device for which to return properties.
    </ParamField>
    
    <ResponseField name="properties" type="_CudaDeviceProperties">
      Device properties object with attributes:
      - `name`: Device name
      - `major`: Major compute capability
      - `minor`: Minor compute capability
      - `total_memory`: Total memory in bytes
      - `multi_processor_count`: Number of multiprocessors
    </ResponseField>
    
    ```python
    >>> props = torch.cuda.get_device_properties(0)
    >>> print(f"Name: {props.name}")
    >>> print(f"Memory: {props.total_memory / 1e9:.2f} GB")
    >>> print(f"Compute: {props.major}.{props.minor}")
    ```
  </Accordion>
</AccordionGroup>

## Memory Management

<AccordionGroup>
  <Accordion title="torch.cuda.memory_allocated()">
    Returns the current GPU memory occupied by tensors in bytes.
    
    <ParamField path="device" type="int or torch.device">
      Selected device. If None, uses current device.
    </ParamField>
    
    <ResponseField name="bytes" type="int">
      Memory occupied by tensors.
    </ResponseField>
    
    ```python
    >>> x = torch.randn(1000, 1000, device='cuda')
    >>> torch.cuda.memory_allocated()
    4000000  # ~4MB
    ```
  </Accordion>

  <Accordion title="torch.cuda.memory_reserved()">
    Returns the current GPU memory managed by caching allocator in bytes.
    
    <ParamField path="device" type="int or torch.device">
      Selected device. If None, uses current device.
    </ParamField>
    
    <ResponseField name="bytes" type="int">
      Memory reserved by caching allocator.
    </ResponseField>
    
    ```python
    >>> torch.cuda.memory_reserved()
    33554432  # 32MB reserved
    ```
  </Accordion>

  <Accordion title="torch.cuda.max_memory_allocated()">
    Returns the maximum GPU memory occupied by tensors in bytes.
    
    <ParamField path="device" type="int or torch.device">
      Selected device. If None, uses current device.
    </ParamField>
    
    <ResponseField name="bytes" type="int">
      Peak memory usage.
    </ResponseField>
    
    ```python
    >>> torch.cuda.max_memory_allocated()
    536870912  # 512MB peak
    ```
  </Accordion>

  <Accordion title="torch.cuda.reset_peak_memory_stats()">
    Resets the peak memory statistics.
    
    <ParamField path="device" type="int or torch.device">
      Selected device. If None, uses current device.
    </ParamField>
    
    ```python
    # Reset stats before measuring
    torch.cuda.reset_peak_memory_stats()
    
    # Run model
    output = model(input)
    
    # Check peak memory
    peak = torch.cuda.max_memory_allocated()
    print(f"Peak memory: {peak / 1e9:.2f} GB")
    ```
  </Accordion>

  <Accordion title="torch.cuda.empty_cache()">
    Releases all unoccupied cached memory currently held by the caching allocator.
    
    This doesn't free memory occupied by PyTorch tensors, only the unused cached memory. Use this when you need to free memory for other processes.
    
    ```python
    # After deleting large tensors
    del large_tensor
    torch.cuda.empty_cache()  # Return memory to GPU
    ```
  </Accordion>

  <Accordion title="torch.cuda.memory_summary()">
    Returns a human-readable summary of memory allocator statistics.
    
    <ParamField path="device" type="int or torch.device">
      Selected device. If None, uses current device.
    </ParamField>
    
    <ParamField path="abbreviated" type="bool" default="False">
      If True, returns abbreviated summary.
    </ParamField>
    
    <ResponseField name="summary" type="str">
      Formatted memory statistics.
    </ResponseField>
    
    ```python
    >>> print(torch.cuda.memory_summary())
    |===========================================================================|
    |                  PyTorch CUDA memory summary                              |
    |===========================================================================|
    |            CUDA OOMs: 0            |      cudaMalloc retries: 0           |
    ...
    ```
  </Accordion>

  <Accordion title="torch.cuda.memory_stats()">
    Returns a dictionary of memory allocator statistics.
    
    <ParamField path="device" type="int or torch.device">
      Selected device. If None, uses current device.
    </ParamField>
    
    <ResponseField name="stats" type="dict">
      Dictionary containing detailed memory statistics including:
      - `allocated_bytes.all.current`: Current allocated memory
      - `reserved_bytes.all.current`: Current reserved memory
      - `active_bytes.all.current`: Current active memory
      - And many more detailed metrics
    </ResponseField>
    
    ```python
    >>> stats = torch.cuda.memory_stats()
    >>> print(stats['allocated_bytes.all.current'])
    4000000
    ```
  </Accordion>
</AccordionGroup>

## Stream and Event Management

<AccordionGroup>
  <Accordion title="torch.cuda.Stream">
    Wrapper around a CUDA stream for asynchronous operations.
    
    <ParamField path="device" type="int or torch.device">
      Device for which to create stream.
    </ParamField>
    
    <ParamField path="priority" type="int">
      Priority of the stream. Lower numbers represent higher priorities.
    </ParamField>
    
    ```python
    import torch
    
    # Create custom stream
    stream = torch.cuda.Stream()
    
    # Operations in stream run asynchronously
    with torch.cuda.stream(stream):
        x = torch.randn(1000, 1000, device='cuda')
        y = x @ x.t()
    
    # Wait for stream to complete
    stream.synchronize()
    ```
  </Accordion>

  <Accordion title="torch.cuda.stream()">
    Context manager that selects a given stream.
    
    <ParamField path="stream" type="Stream" required>
      Stream to use for operations.
    </ParamField>
    
    ```python
    s = torch.cuda.Stream()
    
    # All operations in this context use stream s
    with torch.cuda.stream(s):
        x = torch.randn(100, 100, device='cuda')
        y = x @ x.t()
    ```
  </Accordion>

  <Accordion title="torch.cuda.Event">
    Wrapper around a CUDA event for timing and synchronization.
    
    <ParamField path="enable_timing" type="bool" default="False">
      If True, event can be used to measure time.
    </ParamField>
    
    <ParamField path="blocking" type="bool" default="False">
      If True, event blocks until it's been recorded.
    </ParamField>
    
    <ParamField path="interprocess" type="bool" default="False">
      If True, event can be shared between processes.
    </ParamField>
    
    ```python
    # Time GPU operations
    start = torch.cuda.Event(enable_timing=True)
    end = torch.cuda.Event(enable_timing=True)
    
    start.record()
    # GPU operations
    x = torch.randn(10000, 10000, device='cuda')
    y = x @ x.t()
    end.record()
    
    # Wait for completion
    torch.cuda.synchronize()
    
    elapsed_time = start.elapsed_time(end)
    print(f"Time: {elapsed_time:.2f} ms")
    ```
  </Accordion>

  <Accordion title="torch.cuda.synchronize()">
    Waits for all kernels in all streams on a device to complete.
    
    <ParamField path="device" type="int or torch.device">
      Device for which to synchronize. If None, uses current device.
    </ParamField>
    
    ```python
    # Launch async operations
    x = torch.randn(1000, 1000, device='cuda')
    y = x @ x.t()
    
    # Wait for completion
    torch.cuda.synchronize()
    print("All GPU operations complete")
    ```
  </Accordion>

  <Accordion title="torch.cuda.current_stream()">
    Returns the currently selected Stream for a given device.
    
    <ParamField path="device" type="int or torch.device">
      Selected device. If None, uses current device.
    </ParamField>
    
    <ResponseField name="stream" type="Stream">
      Current stream object.
    </ResponseField>
    
    ```python
    >>> stream = torch.cuda.current_stream()
    >>> print(stream)
    <torch.cuda.Stream device=cuda:0 ...>
    ```
  </Accordion>
</AccordionGroup>

## CUDA Graphs

<AccordionGroup>
  <Accordion title="torch.cuda.CUDAGraph">
    Wrapper around a CUDA graph for optimizing repeated operations.
    
    CUDA graphs capture a sequence of operations and replay them with lower overhead.
    
    ```python
    import torch
    
    # Static input
    static_input = torch.randn(1000, 1000, device='cuda')
    static_output = torch.empty(1000, 1000, device='cuda')
    
    # Capture graph
    g = torch.cuda.CUDAGraph()
    with torch.cuda.graph(g):
        static_output.copy_(static_input @ static_input.t())
    
    # Replay graph (much faster)
    for _ in range(100):
        g.replay()
    ```
  </Accordion>

  <Accordion title="torch.cuda.graph()">
    Context manager for capturing a CUDA graph.
    
    <ParamField path="cuda_graph" type="CUDAGraph" required>
      Graph object to record into.
    </ParamField>
    
    <ParamField path="stream" type="Stream">
      Stream to capture. If None, uses current stream.
    </ParamField>
    
    ```python
    g = torch.cuda.CUDAGraph()
    
    with torch.cuda.graph(g):
        # Operations to capture
        y = model(x)
    
    # Replay captured operations
    g.replay()
    ```
  </Accordion>

  <Accordion title="torch.cuda.make_graphed_callables()">
    Accepts callables and returns graphed versions.
    
    <ParamField path="callables" type="callable or tuple of callables" required>
      Callables to graph.
    </ParamField>
    
    <ParamField path="sample_args" type="tuple or tuple of tuples" required>
      Sample arguments for each callable.
    </ParamField>
    
    ```python
    def model_step(x):
        return model(x).sum()
    
    # Create graphed version
    graphed_step = torch.cuda.make_graphed_callables(
        model_step,
        (torch.randn(32, 100, device='cuda'),)
    )
    
    # Use graphed version (faster)
    for batch in data:
        loss = graphed_step(batch)
    ```
  </Accordion>
</AccordionGroup>

## Performance Optimization

<CodeGroup>
```python Async Copy
import torch

# Enable async memory copy
x_cpu = torch.randn(1000, 1000, pin_memory=True)
x_gpu = x_cpu.to('cuda', non_blocking=True)

# Continue with other work while copy happens
y = torch.randn(500, 500, device='cuda')

# Synchronize when needed
torch.cuda.synchronize()
```

```python Stream Parallelism
import torch

# Create multiple streams
stream1 = torch.cuda.Stream()
stream2 = torch.cuda.Stream()

# Parallel execution
with torch.cuda.stream(stream1):
    y1 = model1(x1)

with torch.cuda.stream(stream2):
    y2 = model2(x2)

# Wait for both
torch.cuda.synchronize()
```

```python Memory Profiling
import torch

torch.cuda.reset_peak_memory_stats()

# Run your code
output = model(input)

# Check memory usage
print(f"Allocated: {torch.cuda.memory_allocated() / 1e9:.2f} GB")
print(f"Reserved: {torch.cuda.memory_reserved() / 1e9:.2f} GB")
print(f"Peak: {torch.cuda.max_memory_allocated() / 1e9:.2f} GB")
```
</CodeGroup>

## Best Practices

<Accordion title="Memory Management">
  1. **Pin memory for faster transfers:**
     ```python
     tensor = torch.randn(1000, 1000, pin_memory=True)
     tensor_gpu = tensor.to('cuda', non_blocking=True)
     ```
  
  2. **Clear cache when needed:**
     ```python
     del large_tensor
     torch.cuda.empty_cache()
     ```
  
  3. **Monitor memory usage:**
     ```python
     print(torch.cuda.memory_summary())
     ```
</Accordion>

<Accordion title="Multi-GPU Training">
  ```python
  import torch
  import torch.nn as nn
  
  # DataParallel for simple multi-GPU
  model = nn.DataParallel(model)
  model = model.cuda()
  
  # Or DistributedDataParallel for better performance
  from torch.nn.parallel import DistributedDataParallel as DDP
  model = DDP(model, device_ids=[local_rank])
  ```
</Accordion>

<Accordion title="Error Handling">
  ```python
  import torch
  
  try:
      if torch.cuda.is_available():
          device = torch.device('cuda')
          x = torch.randn(10000, 10000, device=device)
      else:
          raise RuntimeError("CUDA not available")
  except RuntimeError as e:
      print(f"Error: {e}")
      device = torch.device('cpu')
  ```
</Accordion>
