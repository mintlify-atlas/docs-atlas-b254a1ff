# Quantization

The `torch.quantization` module provides tools to convert floating-point models to quantized versions with reduced precision (INT8) for faster inference and smaller model sizes.

## Quantization Modes

PyTorch supports three types of quantization:

1. **Dynamic Quantization** - Weights are quantized ahead of time, activations are quantized dynamically at runtime
2. **Static Quantization** - Weights and activations are quantized based on observed data distributions
3. **Quantization-Aware Training (QAT)** - Quantization is simulated during training for better accuracy

## Core Functions

### quantize

```python
torch.quantization.quantize(
    model,
    run_fn,
    run_args,
    mapping=None,
    inplace=False
)
```

Quantize a float model using static quantization.

<ParamField path="model" type="nn.Module">
  Float model to be quantized.
</ParamField>

<ParamField path="run_fn" type="callable">
  Function to run the model on sample data for calibration.
</ParamField>

<ParamField path="run_args" type="tuple">
  Arguments for the calibration function.
</ParamField>

<ParamField path="inplace" type="bool" default="False">
  Whether to modify the model in-place.
</ParamField>

<ResponseField name="Returns" type="nn.Module">
  Quantized model
</ResponseField>

### quantize_dynamic

```python
torch.quantization.quantize_dynamic(
    model,
    qconfig_spec=None,
    dtype=torch.qint8,
    mapping=None,
    inplace=False
)
```

Convert a float model to dynamic quantized model.

<ParamField path="model" type="nn.Module">
  Float model to be quantized.
</ParamField>

<ParamField path="qconfig_spec" type="set or dict" default="None">
  Either a set of module types or a dict mapping module types to QConfig.
</ParamField>

<ParamField path="dtype" type="torch.dtype" default="torch.qint8">
  Quantized data type for weights. Options: `torch.qint8`, `torch.float16`.
</ParamField>

<ParamField path="inplace" type="bool" default="False">
  Whether to modify the model in-place.
</ParamField>

### quantize_qat

```python
torch.quantization.quantize_qat(
    model,
    run_fn,
    run_args,
    inplace=False
)
```

Perform quantization-aware training and output a quantized model.

<ParamField path="model" type="nn.Module">
  Float model to be trained with quantization awareness.
</ParamField>

<ParamField path="run_fn" type="callable">
  Function to train the model.
</ParamField>

<ParamField path="run_args" type="tuple">
  Arguments for the training function.
</ParamField>

## Observers

### MinMaxObserver

```python
torch.quantization.MinMaxObserver(
    dtype=torch.quint8,
    qscheme=torch.per_tensor_affine,
    reduce_range=False,
    quant_min=None,
    quant_max=None
)
```

Observer that records min and max values for quantization scale calculation.

<ParamField path="dtype" type="torch.dtype" default="torch.quint8">
  Quantized data type.
</ParamField>

<ParamField path="qscheme" type="torch.qscheme" default="torch.per_tensor_affine">
  Quantization scheme to use.
</ParamField>

### HistogramObserver

```python

    dtype=torch.quint8,
```

Observer that records a histogram of values for optimal quantization parameters.

<ParamField path="bins" type="int" default="2048">

```python

    model,
```

<ParamField path="model" type="nn.Module">

  Whether to modify the model in-place.

```python Dynamic Quantization
import torch
import torch.nn as nn
from torch.quantization import quantize_dynamic

# Define a simple model
class SimpleModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear1 = nn.Linear(10, 20)
        self.linear2 = nn.Linear(20, 5)
    
    def forward(self, x):
        x = self.linear1(x)
        x = torch.relu(x)
        x = self.linear2(x)
        return x

# Create and quantize the model
model = SimpleModel()
quantized_model = quantize_dynamic(
    model,
    {nn.Linear},  # Only quantize Linear layers
    dtype=torch.qint8
)

# Use the quantized model
x = torch.randn(1, 10)
output = quantized_model(x)
print(f"Output shape: {output.shape}")
```

```python Static Quantization
import torch
import torch.nn as nn
from torch.quantization import (
    prepare,
    convert,
    default_qconfig,
    QuantStub,
    DeQuantStub
)

class ConvModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.quant = QuantStub()
        self.conv = nn.Conv2d(3, 64, 3)
        self.bn = nn.BatchNorm2d(64)
        self.relu = nn.ReLU()
        self.dequant = DeQuantStub()
    
    def forward(self, x):
        x = self.quant(x)
        x = self.conv(x)
        x = self.bn(x)
        x = self.relu(x)
        x = self.dequant(x)
        return x

# Setup
model = ConvModel()
model.qconfig = default_qconfig

# Prepare for quantization
model_prepared = prepare(model)

# Calibrate with sample data
for _ in range(100):
    sample_data = torch.randn(1, 3, 32, 32)
    model_prepared(sample_data)

# Convert to quantized model
quantized_model = convert(model_prepared)

# Inference
x = torch.randn(1, 3, 32, 32)
output = quantized_model(x)
```

```python Quantization-Aware Training
import torch
import torch.nn as nn
from torch.quantization import (
    prepare_qat,
    convert,
    default_qat_qconfig,
    QuantStub,
    DeQuantStub
)

class QATModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.quant = QuantStub()
        self.linear = nn.Linear(10, 5)
        self.dequant = DeQuantStub()
    
    def forward(self, x):
        x = self.quant(x)
        x = self.linear(x)
        x = self.dequant(x)
        return x

# Setup
model = QATModel()
model.qconfig = default_qat_qconfig

# Prepare for QAT
model.train()
model_prepared = prepare_qat(model)

# Training loop with fake quantization
optimizer = torch.optim.SGD(model_prepared.parameters(), lr=0.01)
for epoch in range(5):
    for batch in range(100):
        x = torch.randn(32, 10)
        y = torch.randn(32, 5)
        
        optimizer.zero_grad()
        output = model_prepared(x)
        loss = nn.functional.mse_loss(output, y)
        loss.backward()
        optimizer.step()

# Convert to quantized model
model.eval()
quantized_model = convert(model_prepared)

# Inference
x = torch.randn(1, 10)
output = quantized_model(x)
```

```python Module Fusion
import torch
import torch.nn as nn
from torch.quantization import fuse_modules

class FusionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 64, 3)
        self.bn1 = nn.BatchNorm2d(64)
        self.relu1 = nn.ReLU()
        self.conv2 = nn.Conv2d(64, 128, 3)
        self.bn2 = nn.BatchNorm2d(128)
        self.relu2 = nn.ReLU()
    
    def forward(self, x):
        x = self.relu1(self.bn1(self.conv1(x)))
        x = self.relu2(self.bn2(self.conv2(x)))
        return x

# Fuse modules for better performance
model = FusionModel()
model.eval()  # Must be in eval mode for fusion

fused_model = fuse_modules(
    model,
    [['conv1', 'bn1', 'relu1'], ['conv2', 'bn2', 'relu2']],
    inplace=False
)

print(fused_model)
```

## Best Practices

<Accordion title="Choosing Quantization Type">
  - **Dynamic Quantization**: Use for models with large matrix multiplications (e.g., LSTMs, Transformers). Easy to apply, minimal accuracy loss.
  - **Static Quantization**: Best for CNNs and models where activation distributions are consistent. Requires calibration data.
  - **QAT**: Use when static quantization shows accuracy degradation. Provides best accuracy but requires retraining.
</Accordion>

<Accordion title="Performance Tips">
  - Fuse Conv-BN-ReLU sequences before quantization for better performance
  - Use per-channel quantization for weights when possible
  - Start with dynamic quantization, move to static/QAT only if needed
  - Test on target hardware as quantized operations may have different performance characteristics
</Accordion>

<Accordion title="Debugging Quantization">
  - Compare outputs between float and quantized models on sample data
  - Use `torch.quantization.get_observer_dict()` to inspect observer statistics
  - Gradually quantize layers to identify problematic operations
  - Consider using higher precision (e.g., fp16) for sensitive layers
</Accordion>
